# 公共技术底座

[返回全局架构](../../../README.md) · [返回共享能力](../README.md)

公共技术底座为六阶段研发和跨流程能力提供通用资源与接口，按实际规模逐步建设。

| 能力 | 对应 infra 工具 | 为什么需要 |
| --- | --- | --- |
| 算力与环境 | GPU / CPU 资源调度、运行镜像与依赖管理 | 分配资源，保持处理、训练、评测和推理环境可复现 |
| 存储与资产 | 对象存储、元数据目录、模型制品库 | 保存视频与模型，提供版本化资产及访问引用 |
| 任务编排 | 工作流、任务队列、重试与执行状态管理 | 执行依赖任务，恢复长任务并记录运行状态 |
| 平台接入 | Git、DLC、Dataset、Eval 及资产平台适配接口 | 为生命周期汇总和 DataViewer 提供源系统事实与访问能力 |
| 权限与监控 | 访问控制、日志、运行监控和成本统计 | 管理项目与资产可见性，定位故障和观察资源消耗 |

研发模块定义业务产物；生命周期层组织项目目标、依赖与证据；底座管理通用资源、接口与执行状态。工作台的数据展示需保留来源并遵循对应项目和源资产的访问权限。
