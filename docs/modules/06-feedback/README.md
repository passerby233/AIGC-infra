# 06 运行反馈与迭代

[返回全局架构](../../../README.md) · [上一阶段：推理优化与发布](../05-serving/README.md) · [下一轮：目标与基准](../01-goals/README.md)

- **职责**：观察生成质量、任务成功率、耗时和成本，归集用户反馈与失败案例并确定改进方向。
- **输入 → 输出**：线上任务记录、生成结果与反馈 → 可复现的问题集、归因和下一轮迭代清单。
- **Infra 用途**：运行看板关联请求、模型版本与结果；反馈和失败案例管理把现象转为可验证的研发问题。
- **浏览复用**：[统一 DataViewer](../../platform/data-viewer/README.md)用于失败案例回看、条件与结果检查，复用数据和评测阶段的浏览能力。
- **项目关联**：运行事实自动采集，记录 `project_id` 与相关版本，必要时增加 `task_id`；问题、证据和迭代建议进入[项目生命周期管理](../../platform/project-lifecycle/README.md)，由负责人确认优先级与下一步。
- **边界**：运行日志与基础监控复用公共底座；数据问题返回 02，模型问题返回 03，推理问题返回 05，目标调整返回 01。需要回滚时使用 05 的发布能力。
