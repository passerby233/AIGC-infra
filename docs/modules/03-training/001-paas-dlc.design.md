## 目标与范围

模型实验与训练模块使用 PAAS DLC 作为任务创建入口，提供平台任务提交 Skill 的详情入口，并复用关键实验记录协议保存可复现证据。门户负责工具导航与使用说明；任务配置、提交及运行记录由 PAAS 承载。

本轮接入两个用户提供的入口。门户中的“创建 DLC 任务”打开 PAAS 创建页面，“查看提交任务 Skill”打开 Skill 详情。入口已配置不表示门户已安装 Skill、代理提交任务或自动同步任务状态。

## 平台入口与配置

| 配置键 | 默认入口 | 用途 |
| --- | --- | --- |
| `training` | [PAAS DLC 创建页面](https://paas.myhexin.com/mfasset/model/list/createtraintask?projectId=37&tenantId=262&from=trainTaskModelCreate) | 打开训练任务创建页面，保留项目、租户与创建场景参数 |
| `paas-task-skill` | [平台任务提交 Skill](https://paas.myhexin.com/skill-market-front/skill-detail/953847f3-d535-44e0-8a31-9c66060a580a) | 查看 Skill 正文、接入方式和提交要求 |

地址在 `web/config.json` 维护，部署环境可通过不入库的 `web/config.local.json` 覆盖；覆盖后重新构建或启动门户。创建地址去除原链接中记录页面访问上下文的 `__pid`、`__src`、`__enter_time`，保留 `projectId=37`、`tenantId=262` 和 `from=trainTaskModelCreate`。

平台入口需在具备访问权限的公司网络与登录会话中使用。当前只读访问得到前端加载页，尚未读取创建表单和 Skill 正文；以下是实验准备与记录约定，平台字段、支持能力和调用方式以登录后的页面为准。

## 输入、输出与依赖

| 环节 | 需要准备或保留的信息 |
| --- | --- |
| 实验定义 | 本次假设、对应项目与工作项、固定评测口径 |
| 运行准备 | 算法代码提交、镜像 / 依赖版本、启动命令和训练配置 |
| 输入资产 | 数据集版本与位置、基线模型或恢复 Checkpoint 的版本与位置 |
| 资源与输出 | 资源需求、可访问的存储位置、日志及 Checkpoint 输出位置 |
| 提交结果 | 平台实际返回的任务 ID / 链接、提交时的运行配置 |
| 运行证据 | 平台任务状态及日志引用、实际产生的指标与模型资产引用 |
| 评测交接 | Checkpoint、生成 / 评测配置、固定评测集与评测报告引用 |

这些信息用于复现与追溯，不假定是 DLC 表单或 Skill 的同名字段。算力、镜像、存储与访问权限复用[公共技术底座](../../platform/foundation/README.md)；实验样例检查复用[统一 DataViewer](../../platform/data-viewer/README.md)。

## 创建与提交流程

1. 固定实验定义与输入资产，确认启动命令、资源需求及输出位置。
2. 选择创建入口：在 PAAS DLC 页面核对项目、租户并填写表单；使用 Skill 时先阅读其详情，按官方说明完成接入、认证与参数准备。
3. 核对运行配置后提交，以平台实际响应确认是否创建成功，保留任务 ID / 链接。响应不明确时先在平台检查是否已有任务，避免重复创建。
4. 在 PAAS 查看运行记录，保存实际日志、指标和 Checkpoint 引用；任务执行失败时记录可核对的错误证据。
5. 对训练产物执行固定口径的评测，将关键结论、任务引用和模型版本关联到项目实验记录与资产索引。

## 项目与证据关联

项目协议的 `project_id` 来自实际项目的 `project.yaml.id`，必要时增加工作项 `task_id`。PAAS 的数字 `projectId`、`tenantId` 与平台训练任务 ID 属于源平台身份，分别保存，通过运行记录建立映射。若平台支持标签或自定义元数据，可按已确认字段携带项目协议 ID；具体支持方式待核对。

普通运行保留平台证据引用，影响技术或交付决策的实验按 [关键实验记录协议](../../../../algorithm-template/experiments/README.md) 补充假设、比较条件、版本、结果与结论。代码 SHA、数据版本、镜像版本和 Checkpoint 引用指向实际运行资产，不用本次门户文档的提交代替。

任务创建成功表示平台接受了提交；任务完成表示执行结果；模型是否通过验收由[评测模块](../04-evaluation/README.md)按项目要求判断。生命周期汇总未来接入时分别保存源平台状态、验收结论与最近同步时间，缺失证据显示未知。

## 验收标准

- 训练模块与平台工具目录均展示 PAAS DLC 和平台任务提交 Skill，并提供两个独立、可配置的外部入口。
- 创建入口保留项目 `37`、租户 `262` 与创建场景，Skill 入口保留用户提供的详情 ID。
- 模块提供实验准备、创建与提交、结果关联的说明，并能跳转关键实验记录协议及本设计文档。
- 网页只展示已配置入口与说明；真实任务、状态、指标和 Checkpoint 以 PAAS 返回与实际实验为依据。
