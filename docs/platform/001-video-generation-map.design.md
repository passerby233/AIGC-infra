# 视频生成技术汇总

类型：设计 · 状态：已实现

[返回共享能力与技术入口](README.md)

## 目标与范围

在现有门户左侧栏的“平台与工具”下方提供“视频生成技术汇总”。该入口是技术知识浏览页，使用现有七个交叉分类视角，不改变六阶段研发地图或九个模块的职责。

搜索栏下方用一排按钮切换任务与输入输出、生成范式、时序生成机制、模型结构与表示、可控性、训练与推理、能力与核心问题。默认展示第一类；点击按钮仅替换下方的分类说明、分类树与内容面板，保留搜索框、按钮和页面滚动位置。全部 54 个子类和 191 个技术点通过可折叠分类树浏览，配合内容面板显示解释、概念和代表作。

## 输入、输出与依赖

权威内容保存在 `vgm-map/`：

| 来源 | 用途 |
| --- | --- |
| `data/representative-works.json` | 七大类、子类、技术点、作品贡献和分类边界 |
| `research/sources.json` | 作品的正式名称、原始链接、年份与核验范围 |
| `data/knowledge-map.json` | 共享概念的定义与子类关联 |
| 专题及调研 Markdown | 可继续阅读的完整资料与来源记录 |

构建时验证分类 ID、来源和作品类型，合并为 `dist/data/content.json` 的 `videoMap`。全部知识文档和内容 JSON 使用 `AIGC-infra/vgm-map/` 命名空间收录，保持原有相对链接；JSON 资料在文档阅读器中按源文件展示。内容统计从数据计算，当前为 7 个视角、54 个子类、191 个技术点与 71 项不同代表作。

## 展示与交互

| 层级 | 展示 | 行为 |
| --- | --- | --- |
| 大类按钮 | 搜索栏下方的七个单行彩色按钮 | 原位切换；按钮使用 `tablist/tab` 语义，支持左右方向键、Home、End |
| 大类内容 | 当前分类的说明、问题及子类数量 | 用 `tabpanel` 标识；切换大类后恢复该类已选子类、技术点及展开状态 |
| 分类树 | 大类根节点、可折叠子类、技术点叶节点 | 原生 `details/summary` 支持鼠标与键盘；展开全部或收起 |
| 子类内容 | 要点解释、技术分支、相关概念、缓存等进一步分组 | 选中叶节点时同步标记两侧的技术点 |
| 代表作 | 年份、作品类型、当前分类中的贡献 | 原论文/官方项目在新标签页打开；较长列表可展开 |
| 分类边界 | 适用范围与验证限制 | 需要时展开阅读；基础论文、评测、相邻领域分别标注 |
| 搜索 | 七分类的子类、技术点、作品及贡献 | 搜索结果直接进入对应子类；命中的作品自动展开并标记 |
| 完整资料 | 专题、代表作目录、来源目录与 JSON | 复用文档阅读器，支持命名章节锚点及返回技术总览 |

不引入外部思维导图库。分类树用语义 HTML 与 CSS 连接线表达层级，避免密集图节点在长中文名称和手机上难以阅读。桌面使用树与内容两列；较窄屏幕将树置于内容上方，树内部可滚动，整页保持无横向溢出。

七类依次采用蓝、紫、青绿、青蓝、琥珀、绿、玫红。未选按钮使用对应浅底和色条，选中按钮使用实色背景、白色文字；内容说明、树根及面板顶部沿用该类色。手机按钮保持单行，在按钮栏内横向滚动，避免重新堆叠成卡片。

入口为 `#/video-generation`，旧的 `#/video-generation/<view.id>` 子类链接继续兼容；`topic`、`point`、`work` 查询参数保存选中的子类、技术点及作品。按钮、节点和页内搜索结果使用 `history.pushState` 保存选择，不触发门户路由跳转。直接访问、刷新和后退均恢复对应内容。离开页面时移除页面事件监听器。

## 内容维护

`web/video-map.mjs` 保存视角展示文案及子类导读，并读取三份内容 JSON。分类、技术点、作品与来源不在前端重复维护。新增子类时补齐导读和概念关联；新增作品时先登记来源再添加分类映射。修改后执行构建，失败的引用不能进入页面。

相关页面逻辑与样式位于 `web/client/video-map.mjs`、`web/client/video-map.css`，复用现有门户图标、导航、文档阅读器和安全策略。功能不依赖联网安装或运行时 CDN。

## 验收标准

- 左侧入口紧跟“平台与工具”，进入技术页面或知识文档后具有当前页标记。
- 七个大类、54 个子类全部可浏览，子类解释、技术点和代表作与源数据一致。
- 七个按钮在搜索下方单行排列且颜色不同；切换时页面、搜索框和按钮栏保持原位，选中状态唯一，键盘可操作。
- 分类树可展开、收起及键盘操作，选中技术点可在两侧定位。
- 跨分类搜索支持中文、作品名与全角英文，命中隐藏作品时自动展开列表。
- 子类链接可直接访问并刷新，浏览器后退恢复选择，Markdown 命名锚点及 JSON 来源可阅读。
- 桌面及手机均无整页横向溢出，论文链接使用新标签页和 `noopener noreferrer`。
- 原有九个模块、数据工程、平台过滤、文档搜索及反向代理前缀继续通过检查。

验证入口：`npm test`、`npm run test:browser`。浏览器检查覆盖全部 54 个子类，截图生成在不入库的 `.preview/` 目录。
