# 跨视角的代表案例

这些案例校验内容模型，不构成模型性能推荐。核验日期：2026-10-07。unknown 表示本轮资料不足，不表示方法不支持。

## Wan：技术报告对应模型系列

依据：[R04](sources.md#r04)，阅读 v2 的视频 VAE 与模型设计部分；与所有后续 Wan 版本区分。

| 视角 | 本轮可以确认/表达的内容 |
| --- | --- |
| 任务 | 报告包含文生、图生及扩展任务；具体检查点支持表另查 |
| 范式 | 使用 Flow Matching 框架 |
| 时序 | 报告模块描述不能单凭因果 VAE 判定整个生成器因果；具体骨干依赖需补查 |
| 架构 | Wan-VAE、DiT、文本编码、交叉注意力 |
| 控制 | 依具体扩展任务记录，不能将所有条件能力并入基础检查点 |
| 训练推理 | 报告提供数据、训练和加速章节；具体配方/性能不在本轮逐项复核 |
| 能力 | 作者报告多种评估；本站尚无统一设置的复现结果 |

共享节点示例：Flow Matching 在范式入口解释目标，在训练入口解释监督；VAE 在架构入口解释压缩，在效率入口解释编解码成本。

## CogVideoX：技术报告对应模型系列

依据：[R05](sources.md#r05)，阅读 v3 的 2.1–2.2。

架构页可明确连接因果视频 VAE、3D RoPE、Expert AdaLN 和全时空注意力。模型的任务、渐进训练、caption 与评估是其他视角入口。这里不把“因果 VAE”变成“因果生成器”标签，也不把当前版本的输入输出规格自动回填到所有历史版本。

## Self Forcing：方法与概念分开

依据：[R20](sources.md#r20)，作者摘要。

| 视角 | 方法条目的内容 |
| --- | --- |
| 任务 | 具体输入条件/检查点支持仍待查实现 |
| 范式 | 自回归视频扩散 |
| 时序 | 依赖自生成历史的 rollout |
| 架构 | 有 KV 缓存；不凭摘要补造完整网络配置 |
| 控制 | 本轮不推断特定姿态/相机等控制兼容性 |
| 训练推理 | 自生成上下文训练、视频级监督和少步模型的定位 |
| 能力 | 研究暴露偏差及流式生成；性能保持作者报告边界 |

方法实体指向暴露偏差、因果生成和 KV 缓存；三个概念分别维护正文，不把方法名替代它们。

## LongLive：交互长视频是多个维度的组合

依据：[R23](sources.md#r23)，作者摘要。

可以表达因果帧级 AR、长序列调优、窗口和历史锚点，以及提示切换时缓存刷新。长视频能力、实时输出和条件变化分别关联时序、训练推理与能力入口。作者报告的硬件速度不作为所有版本或设备的默认速度。

## LTX-2：联合音视频与输入条件分开

依据：[R41](sources.md#r41)，官方仓库说明；仓库随版本持续更新。

任务页可以展示联合音视频家族入口，架构页可展示 DiT 家族定位。具体检查点、时间依赖、训练目标、控制输入与资源要求尚未逐项核验；不能从家族级“音视频”说明推断所有管线都是相同联合生成流程。

## 两组消歧案例

| 搜索/浏览词 | 应出现的结果区别 |
| --- | --- |
| VAE | 变分潜变量建模；视频 VAE；因果视频 VAE；具体模型的 codec |
| flow | Flow Matching；Rectified Flow；光流运动表示 |
| cache | 历史 KV；去噪特征复用；VAE 卷积历史特征 |
| identity | 身份参考任务；身份控制方法；主体一致性能力；相应评测 |

这些词可以同时命中多个实体；搜索结果通过类型、一句话解释和路径帮助用户选择。
