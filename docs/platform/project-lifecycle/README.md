# 项目生命周期管理

[返回全局架构](../../../README.md) · [返回共享能力](../README.md)

- **职责**：贯穿六阶段，连接项目目标、负责人、工作项、里程碑、依赖、验收、资产与决策，支撑多项目及多人协作。
- **输入 → 输出**：Git 中的项目定义和知识、源平台的执行事实 → 可追溯的项目概览、依赖图、近期进展与验收证据。
- **Infra 用途**：项目规范、证据采集、规则校验、Agent 汇总和统一工作台，让目标与实际结果关联，减少重复登记和人工周报。
- **边界**：[01 目标与基准](../../modules/01-goals/README.md)定义目标和比较口径，[04 评测与验收](../../modules/04-evaluation/README.md)执行评测；本层组织项目与证据，负责人确认结论和阶段推进。
- **轻量起步**：各项目维护 `project.yaml`、`README.md`、`AGENTS.md`，普通运行自动关联，关键实验按需补文档；大型项目可增加 Project Hub。

设计索引：[001 项目生命周期与统一工作台](001-project-lifecycle.design.md)。架构原则已确认，详细字段、接口和产品选型待定义。
