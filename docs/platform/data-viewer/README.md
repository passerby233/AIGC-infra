# 统一 DataViewer

[返回全局架构](../../../README.md) · [返回共享能力](../README.md)

- **职责**：统一数据抽样、实验中间检查、模型结果对比和失败案例浏览，覆盖数据、训练、评测与反馈阶段。
- **输入 → 输出**：现有 Dataset、Eval 平台及本地数据的样本元信息、媒体引用和结果 → 可筛选、浏览和对比的多模态视图。
- **Infra 用途**：共用样本关联、媒体渲染和浏览组件，支持训练数据预览、实验检查以及视频模型对比，减少各方向重复开发预览器。
- **关联**：样本使用稳定标识，模型输出与指标关联对应样本及运行版本；通过[项目生命周期管理](../project-lifecycle/README.md)链接到项目和证据。
- **边界**：数据集、评测记录及资产由原平台维护；本能力提供统一浏览与交互，媒体通过引用加载，平台接入和访问能力复用[公共技术底座](../foundation/README.md)。
