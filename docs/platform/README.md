# 跨流程共享能力

[返回全局架构](../../README.md)

共享能力贯穿六阶段研发，由统一 Project Workspace 展示，按实际需求逐步建设。

| 能力与入口 | 职责 | 为什么需要 |
| --- | --- | --- |
| [项目生命周期管理](project-lifecycle/README.md) | 管理项目定义、里程碑、依赖、证据、验收与决策，汇总多项目和多人工作 | 连接目标与交付，减少重复登记，定位当前阻塞 |
| [统一 DataViewer](data-viewer/README.md) | 为数据抽样、实验检查、评测对比和失败案例提供共用浏览组件 | 接入既有平台，保持跨阶段的多模态浏览体验 |
| [公共技术底座](foundation/README.md) | 提供计算、存储、编排、平台接入、权限和监控 | 共用通用资源与执行能力 |

研发模块定义业务产物；生命周期层关联项目目标、工作项、产物与证据；DataViewer 浏览这些资产；技术底座提供资源和接口。Git 中的定义与源平台的运行事实分别维护，工作台读取可重建的汇总视图。

各能力的详细需求、接口及产品选型待分别确定；后续文档放入对应子目录并更新其索引。
