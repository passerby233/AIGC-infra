# 05 推理优化与发布

[返回全局架构](../../../README.md) · [上一阶段：评测与验收](../04-evaluation/README.md) · [下一阶段：运行反馈与迭代](../06-feedback/README.md)

- **职责**：优化生成速度和显存，提供推理接口，管理版本发布与回滚。
- **输入 → 输出**：通过评测的模型及运行目标 → 完成回归验收的模型 / 配置版本与生成服务。
- **Infra 用途**：推理运行时执行生成；任务管理提供排队、状态查询和结果获取；发布管理关联版本并支持回滚。
- **项目关联**：优化与发布记录携带 `project_id`，必要时增加 `task_id`；发布版本、回归报告与回滚记录关联到[项目生命周期管理](../../platform/project-lifecycle/README.md)中的交付里程碑。
- **边界**：量化或运行配置等影响输出的变化先返回 04 验收，再发布；需要模型蒸馏时由 03 执行训练；算力、队列和结果存储复用公共底座。

研发地图允许并行优化与验证；发布仍需满足已确定的验收规则和项目交付要求。
